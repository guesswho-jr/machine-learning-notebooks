# Machine Learning Projects

A collection of machine learning and deep learning projects developed using Python, scikit-learn, TensorFlow, and Keras.

This repository documents my journey into machine learning, covering fundamental concepts, model development, experimentation, evaluation, and practical applications.

## Technologies & Tools

- **Python** – Main programming language
- **Pandas & NumPy** – Data manipulation and numerical computing
- **Matplotlib** – Data visualization
- **Scikit-learn** – Machine learning algorithms, preprocessing, and model evaluation
- **TensorFlow & Keras** – Neural networks and deep learning
- **Jupyter Notebook** – Interactive development and experimentation

## Projects

### Scikit-learn

Projects exploring traditional machine learning algorithms:

- Logistic Regression
- Decision Trees
- Random Forest
- Support Vector Machines (SVM)
- K-Nearest Neighbors (KNN)
- K-Means Clustering
- Hyperparameter tuning and cross-validation

### TensorFlow & Keras

Projects exploring neural networks and deep learning:

- Artificial Neural Networks (ANN)
- Image classification with MNIST
- Multiclass classification
- Model architecture experimentation
- Overfitting and regularization
- Dropout and early stopping
- GPU-accelerated model training

## Key Concepts

Throughout these projects, I explore:

- Data preprocessing and feature engineering
- Training, validation, and test datasets
- Supervised and unsupervised learning
- Classification and regression
- Neural network architecture and activation functions
- Model performance evaluation
- Confusion matrices, precision, recall, F1-score, and ROC-AUC
- Overfitting, underfitting, and model generalization
- Hyperparameter optimization
